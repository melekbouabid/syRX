## Rate limits

All limits are applied at 90% of the configured value (`http.safety_factor`), and a robots.txt `Crawl-delay` always wins when it is slower.

| Host | Configured | What the provider documents | How it was confirmed |
|---|---|---|---|
| eutils.ncbi.nlm.nih.gov | `http.ncbi`: 3 req/s, 10 req/s with an API key | 3 requests per second without an API key, 10 with one; identify with `tool` and `email` | NCBI E-utilities documentation (NBK25497). The Bookshelf page answered automated requests with a reCAPTCHA browser check, so the text could not be re-read by the pipeline: confirm in a browser. |
| www.ncbi.nlm.nih.gov (NCBI documentation pages) | 2 req/s | - | Only the documentation links are probed there; kept conservative. |
| rxnav.nlm.nih.gov | 10 req/s | No more than 20 requests per second per IP address | RxNav API terms of service; used by the Tujya ingredient step (module 2 corpus). |
| api.fda.gov | 3 req/s | 240 requests per minute per IP address without an API key | openFDA authentication documentation; used by the Tujya label step (module 2 corpus). |
| every other host | `http.default_limit`: 1 req/s, one connection | - | Conservative default. |

## What was found while building the connectors

Measured on 2026-10-13 with the pipeline itself. The SynergyRx synergy sources (DrugComb,
TDC, O'Neil, NCI-ALMANAC, DepMap, GDSC, PubChem, ChEMBL, Europe PMC, PubTator, DrugBank,
PubMed baseline) were removed later (decision D85); their findings are in the git history.

- **DDInter**: licensed CC BY-NC-SA 4.0 (non-commercial, share-alike). Disabled, and it
  refuses to download until `terms_acknowledged: true` is set; the Tujya corpus step sets
  both for this academic project.
- **Documentation pages** (NCBI Bookshelf) sit behind a browser check or a CAPTCHA. They
  are reported as such. The APIs themselves answer normally.
